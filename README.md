# RuleBot
A lightweight, rule-based Python chatbot that recognizes intents from JSON and returns responses, the time, and the weather.

## Features
- **Intent Parsing**: Intent recognition from a JSON file.
- **Text Cleaning**: Removal of accents & conversion to lowercase.
- **Dynamic Responses**: Live temperature (API) & system time.

## How to run it

Download the main.exe from the Releases
That's it!!!!
